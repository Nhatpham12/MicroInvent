# Font in PDF

`NotoSans-Regular.ttf`, `NotoSans-Bold.ttf` – Noto Sans (bản hinted) của Google, lấy từ
https://github.com/notofonts/notofonts.github.io (`fonts/NotoSans/hinted/ttf/`).

Giấy phép: SIL Open Font License 1.1 – https://openfontlicense.org (được phép nhúng vào PDF và phân phối kèm phần mềm).
Dùng để in phiếu xuất PDF có tiếng Việt (OpenPDF nhúng font vào file).
