# MicroInvent Frontend

React, TypeScript, and Vite frontend.

## Run locally

```powershell
npm ci
npm run dev
```

## Current screens

- `/login` — login form
- `/forgot-password` — email, OTP, and new-password flow
- `/catalog/products`
- `/catalog/groups`
- `/catalog/suppliers`
- `/catalog/customers`

Catalog screens currently use local sample data. Create and edit actions only update the current browser session; API integration is not connected yet.

## Validation

```powershell
npm run build
npm run lint
```
